# Rei da Estrada – APK Android (MaGames)

Jogo de caminhão 3D pelas estradas do Brasil. Versão **3.1**.

- Jogar no navegador: https://magames.onrender.com/jogos/rei-da-estrada/
- Baixar o APK: veja a [release v3.1](https://github.com/magames075-lgtm/rei-da-estrada-app/releases/tag/v3.1) (`rei-da-estrada-v3.1.apk`)

## Instalar no Android
1. Baixe o arquivo `rei-da-estrada-v3.1.apk` no celular.
2. Abra o arquivo e permita "instalar apps desconhecidos" para o navegador, se o Android pedir.
3. Toque em Instalar.

Requer Android 7.0 ou mais novo. Pacote: `com.magames.reidaestrada`.
